### 问题1：头部相机和腕部相机未正确打开/关闭

**症状**：
- 头部相机无法捕获图像
- 相机切换失败
- 错误信息：Failed to capture image

**根本原因**：
Baxter机器人的相机需要显式调用`open()`和`close()`方法。之前的实现只是设置了标志位，并没有真正控制相机硬件。

**解决方案**：
更新`bridge/multi_view_vlm.py`中的相机控制方法：

```python
def _enable_head_camera(self):
    """Enable Baxter head camera."""
    try:
        from baxter_interface import CameraController
        camera = CameraController('head_camera')
        camera.open()
        self._head_camera_active = True
        print("  ✓ Head camera opened")
    except Exception as e:
        print(f"  ⚠ Failed to open head camera: {e}")
        self._head_camera_active = False

def _disable_head_camera(self):
    """Disable Baxter head camera."""
    try:
        from baxter_interface import CameraController
        camera = CameraController('head_camera')
        camera.close()
        self._head_camera_active = False
        print("  ✓ Head camera closed")
    except Exception as e:
        print(f"  ⚠ Failed to close head camera: {e}")
```

类似地更新了`_enable_wrist_camera()`和`_disable_wrist_camera()`方法。

**验证**：
```bash

print('Head camera opened')
cam.close()
print('Head camera closed')
```

### 问题2：VLM识别到物体但系统显示"未找到"

**症状**：
```
描述: The '魔方' (Rubik's cube) is visible on the table surface...
✗ 未找到物体: 魔方
```

VLM的描述中明确说找到了魔方，但系统判断为"未找到物体"。

**根本原因**：
1. VLM返回的JSON中`found`字段可能为`false`，即使描述中说找到了物体
2. 这可能是VLM模型的输出不一致问题

**解决方案**：
在`bridge/vlm_client.py`的`_parse_locate_response()`方法中添加智能检测逻辑：

```python
# Smart detection: if VLM provides position and confidence > 0,
# it likely found the object even if 'found' field is missing or false
found = result.get('found', False)
confidence = result.get('confidence', 0.0)
position = result.get('position', [0.0, 0.0, 0.0])

# Override found=false if we have valid detection data
if not found and confidence > 50 and any(p != 0.0 for p in position):
    print(f"[VLM] ⚠ Overriding found=false because confidence={confidence}% and position is valid")
    found = True
```

**逻辑**：
- 如果`found=false`但置信度>50%且位置非零，则认为找到了物体
- 这样可以容忍VLM输出格式的不一致

**额外改进**：
添加了详细的调试输出：
```python
print(f"[VLM] Raw response text (first 500 chars):")
print(f"  {text[:500]}...")
print(f"[VLM] Parsed JSON result:")
print(f"  found: {result.get('found')}")
print(f"  confidence: {result.get('confidence')}")
print(f"  position: {result.get('position')}")
```

```python
class CameraManager:

    def open_camera(self, name):
```
