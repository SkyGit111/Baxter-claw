## 2. 数据流：自然语言到机器人动作

```
用户输入
"把蓝色方块放到黄色方块上"
         │
         ↓
┌────────────────────────────┐
│  OpenClaw Plugin           │
│  ┌──────────────────────┐  │
│  │ LLM 分析             │  │
│  │ - 识别意图           │  │
│  │ - 选择技能           │  │
│  │ - 提取参数           │  │
│  └──────────────────────┘  │
└────────────┬───────────────┘
             │
             ↓
    技能: pick_and_place_relative
    参数: {
      source: "蓝色方块",
      target: "黄色方块",
      position: "on_top"
    }
             │
             ↓
┌────────────┴───────────────┐
│  Bridge Server             │
│  路由到 Primitives         │
└────────────┬───────────────┘
             │
             ↓
┌────────────┴───────────────┐
│  Primitives 执行           │
│                            │
│  Step 1: pick_by_name      │
│    ├─ VLM 定位 "蓝色方块" │
│    ├─ 坐标变换             │
│    ├─ 安全检查             │
│    └─ 执行抓取             │
│                            │
│  Step 2: place_by_name     │
│    ├─ VLM 定位 "黄色方块" │
│    ├─ 计算相对位置         │
│    ├─ 安全检查             │
│    └─ 执行放置             │
└────────────┬───────────────┘
             │
             ↓
┌────────────┴───────────────┐
│  Driver 执行               │
│  - IK 求解                 │
│  - 关节运动                │
│  - 夹爪控制                │
└────────────┬───────────────┘
             │
             ↓
┌────────────┴───────────────┐
│  Baxter Robot              │
│  物理动作执行              │
└────────────────────────────┘
```

## 3. 视觉定位流程

```
┌─────────────────────────────────────────────────────────────┐
│                    视觉定位完整流程                          │
└─────────────────────────────────────────────────────────────┘

Phase 1: 全局定位 (D455 深度相机)
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│  1. 双臂避让                                                 │
│     ├─ 左臂 → home 位置                                      │
│     └─ 右臂 → home 位置                                      │
│                                                              │
│  2. D455 拍摄                                                │
│     ├─ RGB 图像 (640x480)                                    │
│     └─ 深度图像 (640x480)                                    │
│                                                              │
│  3. VLM 识别                                                 │
│     输入: RGB 图像 + "找到蓝色方块"                          │
│     输出: 2D 像素坐标 (x_pixel, y_pixel)                     │
│                                                              │
│  4. 深度融合                                                 │
│     depth_value = depth_image[y_pixel, x_pixel]             │
│     3D_camera = deproject(x_pixel, y_pixel, depth_value)    │
│                                                              │
│  5. 坐标变换                                                 │
│     3D_base = transform_d455_to_base(3D_camera)             │
│     3D_calibrated = 3D_base + calibration_offset            │
│                                                              │
│  结果: [x, y, z] 在机器人基座坐标系                          │
│                                                              │
└─────────────────────────────────────────────────────────────┘

Phase 2: 精细定位 (手腕相机，可选)
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│  1. 移动到物体上方                                           │
│     position_approach = [x, y, z+0.15]                      │
│                                                              │
│  2. 手腕相机拍摄                                             │
│     近距离观察物体                                           │
│                                                              │
│  3. VLM 精确定位                                             │
│     修正 x, y 坐标                                           │
│                                                              │
│  4. 融合全局和局部                                           │
│     final_position = weighted_average(global, local)        │
│                                                              │
└─────────────────────────────────────────────────────────────┘

Phase 3: 执行抓取
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│  使用最终坐标执行 pick() 原语                                │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

## 4. 安全系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                      多层安全验证                            │
└─────────────────────────────────────────────────────────────┘

运动请求: move_to(arm, pose)
         │
         ↓
┌────────┴─────────┐
│ Layer 1:         │  工作空间检查
│ SafetyValidator  │  ├─ X: [0.3, 1.0] m
│                  │  ├─ Y: [-0.8, 0.8] m
│                  │  └─ Z: [-0.3, 0.5] m
└────────┬─────────┘
         │ ✓ 通过
         ↓
┌────────┴─────────┐
│ Layer 2:         │  可达性检查
│ IK Solver        │  ├─ IK 求解
│                  │  └─ 关节限制检查
└────────┬─────────┘
         │ ✓ 通过
         ↓
┌────────┴─────────┐
│ Layer 3:         │  运动安全
│ Motion Control   │  ├─ 速度限制
│                  │  ├─ 加速度限制
│                  │  └─ 轨迹平滑
└────────┬─────────┘
         │ ✓ 通过
         ↓
┌────────┴─────────┐
│ Layer 4:         │  碰撞检测 (实验性)
│ CollisionDetector│  ├─ 实时位置监测
│                  │  ├─ 停滞检测
│                  │  └─ 自动停止
└────────┬─────────┘
         │ ✓ 通过
         ↓
    执行运动
         │
         ↓
┌────────┴─────────┐
│ Layer 5:         │  抓取验证 (实验性)
│ GraspVerifier    │  ├─ 手腕相机拍照
│                  │  ├─ VLM 判断
│                  │  └─ 失败重试
└──────────────────┘
```

## 5. Skills.md 架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Skills-based 架构                         │
└─────────────────────────────────────────────────────────────┘

用户输入 → LLM → 技能选择 → 参数提取 → 执行

┌──────────────────────────────────────────────────────────┐
│  Skills.md (技能定义)                                     │
│                                                           │
│  ┌─────────────────┐  ┌─────────────────┐              │
│  │ 单步技能        │  │ 组合技能        │              │
│  │                 │  │                 │              │
│  │ • pick_object   │  │ • pick_and_     │              │
│  │ • place_object_ │  │   place_        │              │
│  │   direction     │  │   direction     │              │
│  │ • place_object_ │  │ • pick_and_     │              │
│  │   relative      │  │   place_        │              │
│  │ • locate_object │  │   relative      │              │
│  │ • go_home       │  │                 │              │
│  │ • open_gripper  │  │                 │              │
│  │ • close_gripper │  │                 │              │
│  └─────────────────┘  └─────────────────┘              │
└──────────────────────────────────────────────────────────┘
                         │
                         ↓
┌──────────────────────────────────────────────────────────┐
│  LLM 处理流程                                             │
│                                                           │
│  输入: "把蓝色方块放到黄色方块上"                         │
│                                                           │
│  1. 理解意图                                              │
│     → 需要抓取并放置                                      │
│                                                           │
│  2. 选择技能                                              │
│     → pick_and_place_relative                            │
│                                                           │
│  3. 提取参数                                              │
│     source_object_name: "蓝色方块"  ← 要抓取的           │
│     target_object_name: "黄色方块"  ← 参考位置           │
│     relative_position: "on_top"                          │
│                                                           │
│  4. 验证参数                                              │
│     ✓ 所有必需参数已提取                                  │
│     ✓ source ≠ target                                    │
│                                                           │
└──────────────────────────────────────────────────────────┘
                         │
                         ↓
┌──────────────────────────────────────────────────────────┐
│  执行流程 (固定逻辑)                                      │
│                                                           │
│  Step 1: pick_by_name("蓝色方块")                         │
│          ├─ 定位                                          │
│          ├─ 抓取                                          │
│          └─ 验证 (可选)                                   │
│                                                           │
│  Step 2: place_by_name("黄色方块", "on_top")             │
│          ├─ 定位目标                                      │
│          ├─ 计算位置                                      │
│          └─ 放置                                          │
│                                                           │
└──────────────────────────────────────────────────────────┘
```
