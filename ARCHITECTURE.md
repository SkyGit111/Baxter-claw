## 数据流示例：视觉抓取

```
用户: "抓取蓝色小方块"
  │
  ▼
OpenClaw LLM: 选择技能 pick_object(object_name="蓝色小方块", arm="auto")
  │
  ▼
Plugin: POST /vision/pick_by_name
  {
    "arm": "auto",
    "object_name": "蓝色小方块",
    "use_d455": true
  }
  │
  ▼
BaxterPrimitives.pick_by_name():
  │
  ├─ 1. 多视角定位
  │   ├─ 收回右臂 (避免遮挡)
  │   ├─ D455捕获 RGB + Depth
  │   ├─ VLM识别物体 → 2D边界框
  │   ├─ 深度数据 → 3D位置 (相机坐标系)
  │   ├─ 坐标变换 → 机器人基座坐标系
  │   └─ 应用校正偏移 → 最终位置 [0.73, -0.39, -0.25]
  │
  ├─ 2. 自动选择手臂
  │   └─ Y = -0.39 < 0 → 选择右臂
  │
  ├─ 3. 执行抓取
  │   ├─ 检查可达性 (IK求解)
  │   ├─ 移动到预抓取位置
  │   ├─ 打开夹爪
  │   ├─ 下降到目标
  │   ├─ 闭合夹爪
  │   └─ 提升物体
  │
  └─ 4. [实验性] 抓取验证
      ├─ 捕获右腕相机图像
      ├─ 保存调试图像: debug/grasp_verification/grasp_verify_right_20260424_XXXXXX.jpg
      ├─ VLM分析: "夹爪正在抓住蓝色方块"
      ├─ 验证成功 → 返回结果
      └─ (如失败) 打开夹爪 → 重试抓取 (最多2次)
  │
  ▼
返回结果:
  {
    "success": true,
    "message": "Successfully picked 蓝色小方块",
    "arm": "right",
    "position": [0.73, -0.39, -0.25],
    "confidence": 95,
    "grasp_verified": true,
    "verification_attempts": 1
  }
```

## 关键特性

### 1. 手臂自动选择
- 基于物体Y坐标自动选择最优手臂
- Y < 0 (右侧) → 右臂
- Y >= 0 (左侧) → 左臂
- 使用校准后的精确3D位置

### 2. 多视角视觉定位
- Phase 1: D455深度相机 + 头部相机 (全局定位)
- Phase 2: 腕部相机 (近距离精化，可选)
- VLM + 深度融合 → 精确3D位置
- 坐标变换 + 校正偏移

### 3. 实验性功能 (可选)
- **碰撞检测**: 监测运动停滞，检测碰撞
- **抓取验证**: VLM验证抓取成功，失败自动重试

### 4. 安全机制
- 工作空间限制检查
- 关节限制检查
- IK可达性预检查
- 速度限制

### 5. 双臂协调
- 双臂同步抓取
- 手臂间物体传递
- 同步运动控制
- 碰撞避免检查

## 技术栈

- **后端**: Python 3.8+, FastAPI, Uvicorn
- **机器人**: ROS (Melodic/Noetic), Baxter SDK
- **视觉**: OpenCV, RealSense SDK, VLM (Claude/OpenAI/Qwen)
- **前端插件**: TypeScript, Node.js, OpenClaw
- **配置**: YAML
- **测试**: pytest
